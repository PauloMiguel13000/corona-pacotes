# Corona Server – pacotes do Bedrock

Pacotes de recursos do **Corona Server** (Minecraft Java + Bedrock pelo Geyser), servidos pelo GitHub Pages.
O celular baixa os pacotes direto daqui (link https), sem passar pelo túnel do jogo — assim o download não trava
nos dados móveis.

- `corona-<sha1>.zip` – monstros 3D, sons, trajes (Traje do Rei com asas de hussardo) e itens do servidor.
- `GeyserDisplayEntityPack-<sha1>.zip` – pacote da extensão GeyserDisplayEntity.

O nome de cada arquivo leva o começo do SHA-1 dele: arquivo novo = nome novo (o celular não usa cópia velha).
Quem atualiza é o plugin CoronaPack do servidor (config `bedrock-link-site`).
